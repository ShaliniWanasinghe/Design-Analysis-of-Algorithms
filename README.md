# 🌳 Tree and Graph Implementation in MATLAB
This repository includes simple and clear implementations of tree and graph data structures in MATLAB. It covers how to visualize trees and graphs, perform BFS and DFS traversals, extract subgraphs, and use adjacency matrices.

## Files Overview

### 1. `treesample.m`
- Visualizes a simple tree structure with 3 levels
- Uses MATLAB's graph plotting functionality with layered layout

### 2. `BFS_DFS.m`
- Implements both BFS and DFS traversal algorithms
- Outputs traversal order starting from specified nodes
- Works with tree/graph structures in MATLAB

### 3. `exercise.m`
- Comprehensive graph operations including:
  - Graph creation from edge lists
  - Subgraph extraction for specified nodes
  - Adjacent vertex identification
  - Edge and node labeling
  - Graph coloring
  - Shortest path finding between nodes

### 4. `final.m`
- Creates a graph from an adjacency matrix
- Implements graph visualization
- Contains node traversal algorithm using visited markers
- Includes helper function to find next unvisited neighbor
